## EOS、迁移与复用

四个历史 closing-only 工具响应全部用相同输出、原生身份和停止条件
复现，均没有再次触发最终 EOS；每个案例都有已完成的同 context
后继和超过 1000ms 观察窗口的同 clock-domain runtime 快照。
完整生命周期审计中的 55 次实际 EOS 触发全部对应已观察到的 child
最终 RETURN，没有工具起止标记，也没有后续同 context 模型请求。
没有把未来 RETURN、后继请求或采样工具结束时间提供给在线策略。

573 个受控 JOIN 复制命令全部 ACK 并确认 FULL 复用，合计
104.141685 GB，没有发现该组复制在首次使用前丢失身份，也没有记录
服务窗口过期。实际传输可以合并多个命令，不能将命令数当作原生
H2D operation 数。包含 JOIN 完成后恢复的字节不能全部称为提前预取。

65 个可归因 JOIN ticket 中，10 个在完成前实际启动并确认复用，
共 25.818759 GB。源 DAG 仍有 72 次 JOIN；可归因恢复 ticket 与源
JOIN 的统计口径不同，不能互换计数。107 次额外资格授权对应 110 个
不同请求，全部与实际完成的原生服务绑定。授权关联复用为
21.595914 GB，包含完成后复制，与上述提前复用字节不是同一集合。

工具预取实际复制仍为零；独立预测卸载路径只释放 82 tokens，
即 8060928 字节。不能用这些路径解释总 D2H 下降 47.26981%，也不能
把普通原生压力回收计入新增预测卸载。完整 H2D 下降 3.11492%；
其需求部分为 2617.400820 GB，其余为受控 JOIN 恢复。

## 下一步瓶颈

完整工具后继审计覆盖 3474 次后继，FULL 原生排队至首次服务 P50 为
24.303ms，P99 为 19.161 秒，最长为 173.933 秒。其中 506 个排队至少
一秒的后继，累计等待采样区间约 92.990% 为 inactive，约 6.759% 为
active，其余未知。这是最长持有 1500ms 的资格状态采样关联，既不是
精确的状态转换时间，也不是独占原因、物理冷页或可删除 JCT。
一个长等待实例在约 6.27 秒工具调用后排队约 173.93 秒。

本轮 24 个采样恢复批次合计依赖等待 2470.806ms，V345 的 18 个为
2662.835ms。批次数及请求组成不同，不能据此推断全量等待改善，
更不能按采样间隔放大。完整 JCT 路径中，submit 到首次 launch 均值
为 367.044 秒，首次 launch 到原生完成为 853.717 秒；后者包含
交错执行及各种等待，不是纯 GPU 计算。

下一步先核查大上下文请求长时间 inactive 的实际资格和容量决策，
以及其中有多少恢复能与必要的其他计算重叠。不能为增加工具预取量
而驱逐 ready agent，也不继续添加借出、召回或 lease 变体作为创新。
没有新的 GPU 实验排队；继续复用 V345，除非另行声明改变共同负载
或共同引擎。逐层卸载 A、交接同层物理空间给 B 的方案仍未实现，
本轮结果不能验证其收益。
