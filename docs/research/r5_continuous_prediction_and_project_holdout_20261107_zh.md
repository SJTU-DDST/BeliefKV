# R5 连续工作量表达与项目隔离评估

## 问题和实现范围

2026-11-07，用户要求继续优化 R5 的预测表达及泛化证据。目前正在执行的
83 项目、Host400GB、20 初始、mean70、固定 18 测量成员的重复实验保持冻结。
本次只做 CPU 修改、预测评估和部署准备；这组重复实验完成后停止后续 GPU 实验。

现有 serving 用三档概率乘以 `1、0.5、0.25`。条件进度树实际已经计算连续的
`log1p(remaining_model_work)`，随后转成三档概率；已有连续读出仅用于离线诊断。
所以“连续量尚未进入准入”是确认的实现缺口，但不能由此推导更大的 JCT 收益。
尤其是初始任务尚未服务时，仍依赖语义分类头，其信息不能仅靠输出格式补足。

本次增加显式 `continuous_work_readout` 产物合同：

1. 进度阶段复用同一次 MLP 和树前向，发布连续 log-work、残差尺度和调度效用。
2. 使用训练执行初始总工作量的项目等权中位数 `s` 作参考量，效用为
   `E[s / (s + R)]`，其中 `R` 为剩余模型工作量，采用现有校准 log 残差分布。
   这是一种有工作量标尺、连续且有界的启发式，不是平均 JCT 的最优性保证。
3. 初始阶段按训练执行的各档实际工作量计算经验效用，再由语义分类概率组合。
   不再直接指定三档工作量比例；但同档语义分辨率仍受原初始预测头限制。
4. 异步 worker 缓存上述数值；准入入口只读缓存。原失效、结构事件撤销、
   观测积压和支持不足回退保持。JOIN 权利、容量安全及组合目标不变。
5. 原模型没有该字段时保留原概率权重；新合同校验预测器指纹和参考量。
   准备产物明确禁止决策，不因 CPU 检查自动部署或登记 GPU。

`s` 的来源只包括产物明确声明的训练执行，不使用校准、开发或未来请求标签。
工作量单位仍是 `0.01 × 逻辑新增输入 + 输出 token`，不是纯 GPU 秒，也不包含
未来工具时间。工具预测和 KV 卸载路径不变。

## 已完成的 CPU 检查

在当前保留模型上，参考量为 `19144.06`，由声明的 77 次训练执行确定。
对全部 107 次执行每条最多等距取 64 状态，共 6848 个：

- 原三档概率逐值相同，最大误差为零。
- 单次前向连续读出与原离线连续读出逐值相同。
- 单测验证相同 long 概率下的 24000 与 230000 工作量仍能形成不同优先效用。
- 实际组合准入测试验证缓存连续权重能改变逻辑准入集合；不等于 GPU 服务或 JCT。

CPU0、nice19、CUDA hidden、单线程，64 个真实进度状态，每项 640 次交错测量：

| 路径 | 线程 CPU P50 | P99 |
| --- | ---: | ---: |
| 原三档预测 | 132.760us | 140.883us |
| 连续预测，同一次前向 | 149.153us | 159.567us |
| 原离线读出，重复前向 | 262.310us | 271.464us |

新读出相对原三档增加约 16.4us，发生在异步预测 worker。上述数值不代表整轮
同步控制成本或可消除 JCT，也没有测量其对服务进程的完整干扰。

## 首轮项目隔离诊断

合并三份已有因果训练数据：89 个项目、107 次完整执行、78171 个原始状态。
拒绝重复执行、项目身份变化、缺失自然模型工作尾部和任务模板跨分区泄漏。
固定五折，每折用单独的一折项目校准，另一折评价；词表、数值归一化、两个
MLP、条件树、参考量、档位门槛和校准均在各自训练/校准分区重新拟合。
没有复用已经看过待评价项目的模型隐藏表示。

首轮为有界诊断：训练每次执行最多 128 状态，校准和评价最多 64 状态。
配对只在同一外折内进行，先按 workflow 对、再按项目对等权，不比较不同折的
预测尺度，也不把相关快照当独立项目。参数来源于已有开发设计，因此这仍是
探索性的整项目交叉验证，不是新盲测。

| 五折平均，原始预测诊断 | 三档权重 | 连续权重 |
| --- | ---: | ---: |
| ready 跨项目配对排序 | 72.6499% | 72.6570% |
| log-work RMSE | 1.46560 | 0.92684 |

三档的数值工作量仅为概率乘训练档内 log-work 中心的诊断估计，原线上产物并不
发布该连续值。RMSE 和排序比较不是同一问题。连续量减少数量表示损失，但没有
实质提高该组排序。

五折都没有通过保留的校准门槛，主要是 long→short 超限，其中两折还存在
macro-F1 不足。按实际回退规则，两种候选均使用中性权重，排序为 50% 的并列
计分；上表必须标作回退前的数值诊断，不能标作已获准的调度预测精度。
也不能用这次有界训练直接断言当前完整训练模型在未见项目上必然有同样退化。

下一步核对完整训练快照，保持相同项目划分、模型规模、200 epoch、96 轮树和
既有校准门槛，排除每执行 128 快照的采样影响。无论结果方向如何都保留。
