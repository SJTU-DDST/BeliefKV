# 结构化 checkpoint 采集与显式并行接口

冻结 d58efb67 的六项目自然采集及 CPU 后处理已完整结束。805 个模型
请求保留 33,667,535 个输入 token 和 111,073 个输出 token，完整 token、
因果关系、两次新鲜 idle 快照和原进程退出均通过检查。输入总量包含

## 结构化输入的效果与不足

| 形态指标 | 前批 checkpoint6 | 结构化 checkpoint6 |
| --- | ---: | ---: |
| 模型工作 P90/P10 | 1.644 | 2.237 |
| child 调用 P50/P90 | 23 / 38.8 | 16 / 28.6 |
| child 最大调用数 | 56 | 38 |
| JOIN singleton / double | 23 / 7 | 21 / 6 |
| root 并行轮次中位数 | 1 | 1 |
| 嵌套 JOIN | 2 | 0 |
| child 合计模型工作占比中位数 | 76.40% | 55.65% |
| 最大单 child 模型工作占比中位数 | 19.93% | 15.26% |

结构化输入后 child 更短，root 承担的工作更多；但自然任务大小、并行
JOIN 密度及多轮结构仍达不到本轮机制诊断目标。六个 double JOIN 均有
实际共享 decode 服务，六个 root 却仍全部在最终返回时才满足并行委派
最低要求。不能因为自然终态合格，就推广为正式负载或启动 Full 比较。
两个采集的模型输出不同，以上形态变化也不是隔离变量的因果收益。

完整 token 重建的 prompt 审计发现，33 个 child 中 28 个超过 8 次目标，
其第 9 次输入全部含第 8 次提醒；所有抽查输入均含 checkpoint 契约。
本批只读任务源码变化为零，patch 解析错误为零。提示已送达不等于模型
遵从，不应继续通过降低调用硬上限或截断报告来制造短 child。

证据保留在
`experiments/reports/structured_checkpoint_pilot6_20261030/finish_r1/` 和

## 下一候选：一次提交真实并发任务组

在同一 `native_in_graph_parallel_workstreams` 实验 profile 中增加
`parallel_tasks(assignments=[...])`，每组显式提交 2--4 个结构化 checkpoint。
模型仍选择问题、角色、时机和后续组；`task` 继续处理真正不可分的单项
问题。初始工具选择仍为自动，不增加固定 DAG、多轮配额或输出硬上限。

该工具用原生 task 执行路径并发运行成员，再等待全部结果并返回一个
parent 工具消息。成员分别保留真实模型调用、回调、私有状态隔离、
session 和因果身份。runtime 将一个外部调用展开为它实际启动的成员，
记录外部调用 ID 和成员序号，不改写生成 token，也不虚构请求。
原生文件更新及删除标记保留；成员异常显式进入报告。

仅对未满足并行最低要求的最终返回，现有最多两次补充尝试改为要求
`parallel_tasks`，不再要求生成多个外部 task 调用。实际模型服务及
完成 JOIN 的校验仍保留。此干预需要继续在源报告中披露。

新的 `parallel_checkpoint_pilot6_20261030` 单独声明，保留上一批全部
六个原项目、任务文本、访问类型、上下文、工具环境及 4/8 child、
8/16 root 软预算。单项 checkpoint 格式仍为协议 3，并行 API 单独
记录为版本 1；整体契约指纹改变，旧采集不会因此重新解释。
这是 workload/runtime 接口准备，不是 KV 调度创新或性能收益。

## 采集与后续验收

定向检查 80 项通过，覆盖同步/异步真实并发、嵌套 JOIN、实际 session
归属、一个 parent 结果、无效组参数拒绝，以及原生 Qwen3-Coder parser
对嵌套对象数组的完整解析和 1/7/64 字符流式分块。完整当前源绑定
回归通过 5600 项及 12 项子测试，无失败、错误或跳过，保留此前
全部 5571 项身份；2100 项绑定输入和原生引擎在执行期间未变。
CPU 检查不能替代新自然采集的模型行为与压力证据。

小规模采集先检查多轮多成员 JOIN、child 长度、任务工作差异及原始
源码变化；形态合格后再扩展不同项目人口并校准持续到达。源形态、
实际物理容量压力和调度收益分别验收。保留 JOIN/EOS 预取，工具预取、
逐层 handoff 和 mixed chunk 仍关闭。

持续到达采用预热后的固定到达组完整 JCT，相同背景表覆盖全部测量
对象；不按最先完成者挑样本。需要另外验证 ready-paused 候选各自
可容纳但合计不可容纳、准入后真实获得服务，以及 Host/HBM 对存活
有效 KV 的容纳能力。不能以 native 更多重算或 Full 获胜筛选负载。
