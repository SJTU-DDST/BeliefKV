# 已输出内容预测 child RETURN 的快速初筛（2026-09-28）

问题是 child 已经进入最终自然语言报告后，已生成内容的词形
能否提供比固定长度先验更准确的剩余时间信息。此试验只读复用
原有 1024 字符阶段的项目隔离输入；脚本为
`scripts/pilot_child_report_token_prefix.py`，报告为
`experiments/raw/qwen35_report_length_project_holdout8_20260926_v1/`
`token_prefix_quickcheck_20260928.json`。输入项目、任务、自然
RETURN 资格及时间标签与该目录既有的
`prefix_structure_holdout.json` 相同。

从保留的完整 child 报告截取最前 1024 字符，与实时记录的
1024 字符阶段按 child 身份及最终总长度核对。仅取已出现
该阶段的自然 RETURN；不读取后续文本作为特征。对已看到
的字符 3--5 元组与词形 1--2 元组分别做 TF-IDF 及正则化
对数剩余长度拟合。正则和特征类型只在训练项目留一回放上
按 task 等权误差选取（选中字符 3--5 元组、正则 0.1），
留出项目不用于选择。长度乘当时已观测的文本生成速率，
并加仅从训练项目拟合的收尾时长。

| 预测方式 | 留出 RETURN P50 绝对误差 | 500 ms 内 | JOIN-last 500 ms 内 |
| --- | ---: | ---: | ---: |
| 固定长度先验 | 1603 ms | 2/15 | 0/2 |
| 既有粗前缀结构 | 1144 ms | 4/15 | 0/2 |
| 本次已输出词形 n-gram | 1769 ms | 4/15 | 0/2 |
| 事后最终长度 oracle（不可在线） | 259 ms | 13/15 | 1/2 |

训练 52 条自然 RETURN、20 个 workflow；留出 15 条、7 个
workflow，仅 2 条完整 JOIN 最后 child。新增词形模型的
RETURN 平均绝对误差 1473 ms、JOIN-last 2645 ms。
同一小样本上，浅层文本 n-gram **没有带来可用增益**；
不将该模型接入在线预测或调整物理动作门禁。

此结果尤其**不是**对动态 child RETURN 分类器的检验：
样本只有已知最终自然返回的正例，缺少以同样方式交付的
非终态轮次、继续工具调用与删失负例。前缀取自事后保存的
完整报告；旧 trace 未保存逐 token/逐 chunk 原文及真实交付
时刻，不能证明这些词形在阶段时已被调度器读取。本实验
使用字符和词形而非 Qwen tokenizer 的原始 token ID，也
没有语义或 hidden-state 模型，不能据此否定这两种方法。
下一步应先补非终态流式负例与低开销、身份绑定的实际
接收时间戳，再比较固定前缀与逐片段更新的内容风险。
