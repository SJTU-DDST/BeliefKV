# Child 阶段语义与独立校准：第二阶段

日期：2026-09-30。

## 本阶段目标

检验预训练语义表示及任务适配能否减少终态阶段误报；独立校准阶段
分数、token 点估计偏差与 token 工作区间。把阶段判别、工作量精度、
区间覆盖和传输策略分别验收，不将扩大区间描述为精确预测改进。
不修改 agent guard，不强制取消 child，不直接授权 H2D。

## 语义头与校准

冻结 `sentence-transformers/all-MiniLM-L6-v2`，revision
`1110a243fdf4706b3f48f1d95db1a4f5529b4d41`。权重在同一
`beliefkv-next` 环境中加载，使用 safetensors，不执行远程模型代码。
原始正文/标签不上传模型服务。编码末尾有界已送达历史最多 256 BPE
token，拟合侧 PCA 压缩至 32 维，与八项事件/进度特征组合。
环境沿用 Python 3.11 的 `beliefkv-next`：PyTorch 2.13.0+cu130、
Transformers 5.12.1、NumPy 2.3.5、SciPy 1.17.1。完整版本记录在
冻结对照的 `report.json` 中，没有升级 serving 框架或更换 Qwen 模型。

对照包括数值/事件头、冻结语义头、轻量 CNN，以及只读通知信号。
另固定 4 epochs、seed 21，仅微调 MiniLM 最后两层，训练项目不变，
不以校准或验证的损失 early-stop。GPU 仅用于小编码器训练，不启动
新的 agent workload，完成后模型移回 CPU。

阶段分数温度和 token 偏差在第一份 Astropy 子集上估计；nominal
80% 的 token 边界余量在独立的第二份子集上，用每个 workflow 的
最大观测快照残差做有限样本分位数。重复快照不能增加独立校准
workflow 数。跨项目 exchangeability 未验证，必须看实际 Sphinx
覆盖率；此边界不是重新估计出的 P10/P90，也不是 RETURN 时间区间。

在校准子集上选取至少五个请求、精确率至少 90% 的建议性分数档位，
随后原样应用于验证集。它只是只读统计，不是 agent 门禁或物理
传输许可。不存在该档位时应报告无可用校准档位，不制造通过结果。

## 初始冻结编码器结果

校准集约 90% 的档位在 Sphinx 上未保持精确率：

| 头 | 正确首次触发 | 工具误报 | 精确率 | RETURN 召回 |
|---|---:|---:|---:|---:|
| 数值/事件，校准档位 | 26 | 13 | 66.7% | 74.3% |
| 冻结语义，校准档位 | 33 | 29 | 53.2% | 94.3% |

冻结语义头的所有已观测快照 workflow 覆盖从 3/10 提高到 9/10，
平均 token 区间宽度从约 398 提高到 646；这是范围变宽，不是点
预测变准。首快照 token MAE 约 86，简单检查点先验约 79。
因此冻结预训练表示没有证明比旧模型更准确。

完整冻结编码器+头的 CPU P50 约 6.23 ms，P95 约 29.83 ms；
缓存表示后的头约 0.072/0.081 ms。该开销不能放入逐 token 的
scheduler 主路径；在线接入须异步或按事件/有界频率执行。

## 任务适配结果

仅微调最后两层的四轮训练约 5.43 秒，PyTorch 峰值分配显存
约 689 MiB；结束后 GPU 恢复空闲。适配权重 SHA256 为
`962c85140d46c4a811a4d05c3a120af2918bf85c3de67d8f478891abd039471d`。
下面均为相同 Sphinx 验证集，Astropy 选出的档位原样应用，
未在 Sphinx 上训练或调节该阈值：

| 模型 | 正确首次触发 | 工具误报 | 精确率 | RETURN 召回 |
|---|---:|---:|---:|---:|
| 冻结语义，校准档位 | 33 | 29 | 53.2% | 94.3% |
| 适配语义，校准档位 | 33 | 6 | 84.6% | 94.3% |

固定 0.5 分数档、未经分数校准的适配语义头为 34 次正确触发和
八次误报（81.0% 精确率、97.1% 召回），matched CNN 对照为
34 次正确触发和 28 次误报（54.8% 精确率、97.1% 召回）。
这说明本轮阶段判别的主要改善来自任务适配，并非仅改变分数档位。
固定 0.95 的校准分数档为 25 次正确、三次误报，即 89.3% 精确率、
71.4% 召回；分数数值仍不等于该项目上的精确率。

条件工作量点误差（单位 token）：

| 检查点 | 自然 RETURN | 检查点先验 MAE | 冻结语义校准 MAE | 适配语义校准 MAE |
|---|---:|---:|---:|---:|
| 首快照 | 35 | 78.7 | 86.2 | 76.0 |
| 128 字符 | 35 | 91.2 | 111.7 | 79.1 |
| 512 字符 | 30 | 86.3 | 107.5 | 93.4 |
| 1024 字符 | 26 | 59.5 | 66.0 | 65.0 |

适配头比冻结表示更好，但没有全面优于简单先验，不能声称剩余工作
预测已经足够精确。适配头的原始区间完整观测 workflow 覆盖为 4/10，
独立校准后为 9/10；平均区间宽度从约 383 增加至 545 token。
冻结语义的校准区间约 646 token，同样覆盖 9/10。
适配后在同一覆盖下区间有所缩窄，但仍远大于亚秒传输所需尺度。

验证只有十个 workflow 和 35 个自然 RETURN，且校准/验证跨项目
exchangeability 未验证；所有覆盖与精确率都是本次回顾性实测，
不是正式泛化保证。验证中的工具首次触发可来自真实工具继续执行，
不要把 stage score 当作 child 已完成的证明。

## 交付与未完成工作

`SemanticReportPredictor.load(...)` 可加载冻结或适配的校准头，
返回 request/context/epoch 绑定的阶段分数与条件 token 边界。
它由单个异步消费者持有，支持有界文本表示缓存；缓存重用不重用
旧请求身份或 epoch。完整 CPU 编码+头 P50 约 6.23 ms，P95 约
30.03 ms，缓存表示后的头约 0.072/0.081 ms。不能内联到逐 token
或 scheduler 主线程路径；当前尚未连接线上事件处理或物理迁移。

本阶段已完成预训练语义、任务适配、独立校准、隔离验证和只读产物
交付。下一步是运行条件匹配、带新版通知的全新项目数据，在异步
shadow 下检查分数时效和每请求成本，并继续缩小剩余工作误差。
child 阶段判别改善不等于精确 JOIN 时刻或已证明 H2D/吞吐收益。
本轮没有新增 guard、终态格式限制或 agent 取消路径。
