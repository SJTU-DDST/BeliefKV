# 36-root child RETURN 剩余时间预测探索（2026-09-30）

实验评估集：`experiments/raw/qwen35_child_service_stream_36root_35_65_v1`，
43 个自然 RETURN，有客户端已投递正文和可确认的同请求 decode 服务。
各检查点只选第一次到达 32（首快照）、128、512、1024 字符的快照；
没有达到检查点的 child 不计入该检查点。训练和验证严格按项目拆分；
线上不能事先知道这轮会自然 RETURN，本报告只评估终态轮次的条件 ETA。
标签仍为快照到 RETURN 的客户端单调墙钟时间，包含其后无服务间隙。

新增候选特征为快照之前、同一请求的首次及最近 decode 服务之间的
累计有效速率、累计时长、最近服务批大小。服务端时间用现有上下界及
100 ms 时钟保护映射到客户端快照，所有用于特征的服务完成时间必须在
保守截止线之前；快照之后的最终长度及后续服务不用于预测。
滚动文本阶段特征改为以该快照之前的全部已筛选历史为输入。

比较了对数/线性标签的岭回归、Huber、通知长度与已生成 token 和
速度组合、五近邻及文本历史。模型在外层留出项目以外的数据拟合；
各外层训练折再次按项目拆分、只在本轮其他项目上选候选模型，
未使用外层项目的任意旧样本。旧的两批 32-root trace 是额外训练数据，
模型配置和到达压力不同，不能替代新的未见项目测试。数据量是按项目
重复采样的轮次，不应视为独立同分布样本数。

| 检查点 | RETURN | 原 joint MAE | 本轮训练+历史特征：嵌套选型 MAE | 加入旧训练数据：嵌套选型 MAE | 加入旧数据后 ±500 ms |
|---|---:|---:|---:|---:|---:|
| 首快照 | 43 | 7.76 s | 10.33 s | 7.38 s | 0/43 |
| 128 字符 | 43 | 7.55 s | 6.50 s | 6.51 s | 1/43 |
| 512 字符 | 42 | 7.10 s | 4.81 s | 4.59 s | 5/42 |
| 1024 字符 | 41 | 5.88 s | 4.33 s | 4.40 s | 2/41 |

在旧数据辅助训练的同一批次上，按 workflow 重采样的 512 字符
配对 MAE 改善为 2.51 s（95% 区间 1.53--3.50 s），1024 字符为
1.48 s（0.54--2.41 s）；首快照区间跨零。
该区间不包括多方案探索的选型偏差，也不能证明线上同压力泛化。
低精度的通知长度估计与高波动的未来交错等待仍限制首快照 ETA；
后期快照虽有所改善，但离亚秒级控制目标有显著距离。

评估器：`scripts/evaluate_child_return_eta_candidates.py`。
逐样本比较和详细样本覆盖分别保存于本轮 raw 目录的
`child_return_eta_candidate_extra32_project_loo_v4_rows.jsonl` 和
`child_return_eta_candidate_extra32_project_loo_v4.json`。
所有候选仅在离线诊断中使用，尚未在 scheduler/runtime 上线；
上线前须在未见项目上复验、输出终态/工具轮次判别质量并完成
在线服务特征传递、容量与首次复用的端到端验证。
