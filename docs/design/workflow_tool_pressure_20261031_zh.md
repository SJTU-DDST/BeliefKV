# 工具感知的工作集压力选择

本次修复针对用户指出的冲突：剩余工作量不能覆盖工具等待状态，否则可能保留长工具阻塞者，反而暂停可以执行的 child。用户随后澄清“暂不进行长工具替换”指不替换 trace 的工具时长。长工具 A→B 属于预测卸载链路，继续保留，不增加独立开关；prepare_host、JOIN/EOS 预取、驻留耦合和两秒普通合并窗口也继续保留。

## 原实现的区别

当前复现的 ThunderAgent acting decay 在恢复选择时折算逻辑额度，年龄来自实际模型完成，半衰期为一秒。五秒是论文臂的控制周期，不是折扣计算的步长。恢复之后，容量检查使用完整上下文和 buffer，原压力规则先暂停 acting，再按请求完成边界处理 reasoning。

此前 Full 的 `workflow_remaining` 只在这个压力阶段按剩余工作选择对象，没有工具剩余等待因素；后继先登记还可能把真正等待工具的 agent 变成 `pending=True, acting=False`，使它逃过 acting 阶段。论文臂与历史实验保持原实现。

## 新策略

Full 显式选择 `AGENT_PRESSURE_PAUSE_POLICY=workflow_tool_aware`。同一控制边界缓存一份工具状态，用于可恢复额度和压力对象选择，不扫描 KV 物理路径，也不在 decode 步上调用新的模型。

1. 工具开始后的一个控制周期内保留完整额度，避免将短工具等待制造成恢复空间。默认 Full 控制周期为两秒；新工具开始重新计时，不沿用前一次模型完成后的旧年龄。
2. 有当前有效工具分布时，使用“已经等待到现在，未来 H 内返回”的条件概率 p。H 为控制周期与该上下文完整 D2H/H2D 往返估计的较大者。传输估计复用已有缓存；冷启动的 8 GB/s 只是工程回退，不是实测带宽。
3. 保留权重为 `min(1, p / (1 - minimum_survival))`。现有 minimum_survival 为 0.75，因此返回概率达到 0.25 时仍计完整额度。预测过期、缺失或尾部无支持时，在短保护期后按实际等待时间衰减，半衰期一秒，不永久保留工具额度。并行工具组没有伪造单工具预测，按最新未返回工具的观察起点保守回退。
4. buffer 不打折。被折扣的额度只决定尝试恢复谁，恢复后的完整原始额度仍须协调；逻辑折扣不构成物理可用页。
5. 实际超限时，先比较可安全暂停的阻塞者。将相同保留权重档内的剩余工作量用于选择，较长工作先暂停；缺少工作预测时退回原上下文顺序。低保留权重的长阻塞者先于短工具续接。所有阻塞者都不可安全暂停时，正在执行的请求只记录完成边界的暂停标记，标记不释放额度。
6. `pending` 不再等同于实际计算。后继已登记但依赖未完成时，仅当当前身份一致、没有原生请求行、没有分配或提交的可变 KV、没有输出、没有重取标记且不在运行批次中，才允许立即逻辑暂停。保留请求本身，工具实际结束后重新竞争恢复。
7. 已选恢复、有效 JOIN/EOS ticket、恢复驻留保护及 ready JOIN parent 保留保护。仍被工具/JOIN 阻塞的 paused agent 不会仅因预测时间到期而重新激活。

这里没有在容量不足之外额外抢占 ready agent，也没有恢复普通请求的额外租约。逻辑选择不能保证原生页恰好可以回收；物理卸载仍需真实 Host 副本、引用、锁、DMA 和分配器检查。原生无法释放的情况应单独记录，不能把逻辑暂停算成 HBM 释放或 JCT 收益。

## 开关与验证

误解用户指令时曾在未提交代码中加入独立 A→B 开关并关闭该路径，现已全部撤销。此前 CPU 候选和中断回归留档为被澄清取代的准备，不是 GPU 实验，也不能作为最终源码资格。

下一轮选择 12 个初始 workflow 和平均 70 秒到达，复用既有到达表及固定测量组；不重采源 trace，也不修改或重采样工具时长。此选择用于补充在途人口和可执行候选，不能预先保证消除背景覆盖与 Host 容量问题，必须重新检查。

`scripts/prepare_tool_aware_pressure.py` 准备相同修复、工具卸载与两秒窗口下的 control/oracle 配置。两者均保留 oracle 进度记账以匹配控制开销，但 control 不使用未来剩余工作量选择任何准入或压力对象；保留原类别、上下文顺序及工具权重。它是机制对照，不包装成论文 ThunderAgent baseline。oracle 开启剩余工作量排序。两个 artifact 只在 `remaining_work_ranking_enabled` 上不同，真实输入、输出、依赖图及工具时间均不修改。先运行该负载的修复对照，再运行相同条件下的 oracle。

验收保留完整固定测量组 JCT、共同窗口吞吐、实际授予到原生服务、工具暂停/再次恢复、迁移和额外重算，以及控制 CPU 时间。CPU 测试证明状态和容量边界，不证明 GPU 或完整工作负载收益。
