# 工具生存曲线查询降本

日期：2026-10-23，北京时间。基线为 main 的 `2c02028`。

本轮只优化工具时长模型的曲线查询，不改变卸载概率门槛、预取触发、
CDF、分位数定义、截尾处理或调度策略。V128 继续使用冻结的
`04191b0`；本补丁不进入正在运行或已经排队的六组实验。

## 保留的实现

`KaplanMeierCurve` 在拟合和反序列化后创建只含已有时间点的
`_step_times` tuple。`survival` 对该 tuple 做原有的右侧二分查询，
再从原 `_steps` 返回同一生存概率，省去每次比较时的 tuple 字段提取。
重新拟合、空样本和纯截尾曲线都替换该索引；序列化字段不变。

分位数仍使用原来的线性条件扫描和浮点除法。没有增加按请求维护的
预测缓存、重试频率、KV 观察或高频失效管理。新增状态仅属于已拟合曲线，
随原有曲线缓存一起失效。

## 未采用的候选

先前尝试直接二分查找条件分位数。V2864 在当前历史的部分重复查询中
略快，但 V2865 的完整小历史对照发现，4--16 条样本的查询会慢约
6%--19%。因此没有保留该实现。

V2863--V2865、原始样本以及
`v2864_quantile_candidate_source_20261023.py` 全部保留。该候选源码
SHA-256 为
`65aef69f0e2d47acdae3c32ca2e5f606a8234ed70cca6dcd6f175b5e44d66948`，
与两个候选性能报告的源码绑定一致，不作为最终补丁的通过或性能证据。
